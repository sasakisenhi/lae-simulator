## 4. ゲーム制作プロジェクト

### 4.1 Project CIEL（シエル）

- **[設定]** 大型オープンワールドアクションRPG。2027年後半発売予定。
- **[設定]** ゲーム開発部門から340名が参画。自社製C++ゲームエンジンを使用。
- **特徴**：膨大な地形・アセット・ゲーム状態。開発機でのデバッグや長時間のビルド・検証が必要。
- **主要課題**：不具合報告に必要な操作履歴・ログ・ビルド情報が分散し、追加確認が発生する。
- **補足**：340名はゲーム開発部門の所属者数。QA、ローカライズ、基盤担当者は別部門であり、これに上乗せされうる。

### 4.2 Project LANTERN（ランタン）

- **[設定]** 協力型アクションゲーム。2028年発売予定。
- **[設定]** ゲーム開発部門から190名が参画。Unreal Engineを利用。
- **特徴**：ネットワーク・マルチプレイ関連のテストやサービス利用が多い。
- **主要課題**：テスト関連の支援サービス、環境の複製・破棄、ネットワーク検証の再現性。

### 4.3 Project MOSS（モス）

- **[設定]** 新規IPの試作プロジェクト群。ゲーム開発部門から70名が参画。
- **特徴**：短期間で複数の試作を反復するため、設計・技術の自由度が必要。
- **主要課題**：大規模タイトル向けの標準ルールが、かえって小規模チームの試作速度を損なう可能性。
- **補足**：「すべての開発環境を一律に統合するべきではない」という反例を提供する。

**人数整合**：340 + 190 + 70 = **600名（ゲーム開発部門の全員）**。人数はある時点の主所属であり、横断支援の兼務は二重計上しない。
