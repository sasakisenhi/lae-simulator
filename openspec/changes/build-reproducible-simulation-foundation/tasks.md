本一覧は改訂後のMVP実装計画。全件未着手であり、Exploreの紙上追跡や本計画の検証を実装完了とは扱わない。WDxx=world-definition、SExx=simulation-execution、EPxx=evidence-projectionのRequirement先頭ID。D番号は改訂後design.md。旧18件との対応はDesignのMigration Planにある。
